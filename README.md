# Git Lab Project

A small calculator used to practise Git.

## How to Run
python calc.py

## Project Structure
- calc.py - Calculator functions (add, subtract, multiply, divide)
- notes.md - Git workflow notes

## Reflection

In this lab I created a Git repository, cloned it, created a feature branch, and resolved a merge conflict in calc.py. I also added a .gitignore file, wrote a README, and reorganized the project into src/, docs/, and tests/ folders. This helped me understand how Git tracks changes, how branches work, and how to fix conflicts when two people change the same file.
